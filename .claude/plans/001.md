# Easy ABC — เว็บแอปเกมสะกดคำสำหรับเด็ก (ตามโครง skills ของโปรเจกต์)

## Context

สร้างเว็บแอปเกม "Easy ABC" โดยใช้ `public/easy-abc/social-promote.png` เป็น requirement spec และ**เป้าหมายดีไซน์ของ UI หลัก**: เกมสะกดคำภาษาอังกฤษสำหรับเด็ก UI ภาษาไทย, แผนที่ด่าน 1–5 + ระบบดาว, ดูรูป→เรียงตัวอักษร (🐶 → D-O-G), เสียงอ่านออกเสียง, เล่นได้ทุกอุปกรณ์

**การตัดสินใจจากผู้ใช้ (สรุปสุดท้าย):**

- **Zustand** เก็บ local data ทั้งหมด (progress/entitlement/energy/settings/theme)
- **Static repo** (hexagonal ports & adapters) เก็บ master data แทน DB
- **ด่าน 1–5 ฟรีทั้งหมด** ปลดด้วยการเล่นผ่านด่านก่อนหน้า — เข้าผ่าน URL ตรงได้ แต่หน้าเล่นเช็คสิทธิ์จาก zustand (client-side ล้วน **ไม่ซีเรียสความปลอดภัย** by design)
- **IAP = ปลดล็อกโหมดเกมพรีเมียม 4 โหมด** ขายโหมดละใบ + Bundle · ชำระผ่าน **PromptPay QR auto-approve** (_ตั้งใจไม่ตรวจสอบการชำระ_ จะแก้ทีหลัง) · PromptPay ID + ราคา = placeholder ใน master data
- **ระบบ Energy สไตล์ Candy Crush แบบไม่กดดัน** (ดูหัวข้อ Energy)
- ธีม: โครงเต็มตาม skill nextjs-semantic-theme, ธีม **sky (default) ต้องถอดลุคจากภาพโปรโมต**, ThemeSwitcher เป็นของสำรองอยู่ในหน้าตั้งค่า, **dark mode ใช้งานได้จริง**
- รูปคำศัพท์: รองรับไฟล์จริง `/easy-abc/words/<word>.png` ที่จะเพิ่มทีหลัง, fallback = emoji
- เสียง: Web Speech API + Web Audio chimes (ไม่มีไฟล์เสียง)

**Skills ที่ต้องยึด (อ่านครบแล้วใน `.agents/skills/`):**

- `nextjs-hexagonal-repo` — port ใน domain (framework-free), adapter คืน `Result<T>` ไม่ throw, contract test, eslint gate
- `nextjs-semantic-theme` — semantic token ชุดเดียว `[data-theme]`, `theme.css` = `@theme inline` var()-only, hex อยู่ `themes/*.css`, dark = พลิก ramp + `--on-brand`, Zustand `theme-storage` + ThemeProvider + ThemeScript (FOUC) + `suppressHydrationWarning`
- `nextjs-versioning` — version จาก `package.json` ที่เดียว → footer `vX.Y.Z (sha)`, `release:*` scripts, CHANGELOG
- `nextjs-monorepo-versioning` — ไม่ใช้ (single app + npm)

## ระบบ Energy (Candy Crush-inspired — ออกแบบให้ไม่เครียด)

- **⚡ สูงสุด 10** · **หัก 1 เมื่อ:** เริ่มด่านที่*ยังไม่เคยผ่าน* หรือเริ่มรอบในโหมดพรีเมียม
- **ไม่หัก:** เล่นซ้ำด่านที่เคยผ่านแล้ว (ฝึกซ้ำได้ไม่จำกัด — จุดสำคัญกันเครียด), เข้าดูแผนที่/เมนู
- **โบนัส:** ได้ 3 ดาวครั้งแรกของด่าน → +1 ⚡ (ไม่เกิน max)
- **Auto-restore: +1 ทุก 5 นาที** (เต็มหลอดจาก 0 ใน 50 นาที — เร็วกว่า Candy Crush มาก โดยเจตนา)
- **ของขวัญรายวัน 🎁:** เปิดแอปครั้งแรกของวัน → เติมเต็มหลอดฟรี + toast น่ารัก
- Energy หมด → modal ปลอบใจ "พักสายตาแป๊บนึงนะ ⚡ กำลังชาร์จ..." + countdown ถึงแท่งถัดไป + ปุ่มไปร้านค้า (Bundle = ไม่จำกัด) — **ไม่มี**การขายเติม energy แยกใบ ไม่เด้งบ่อย ไม่บล็อกการเล่นซ้ำด่านเก่า
- ผู้ซื้อ Bundle: แสดง ⚡∞
- กลไก: `energy.store.ts` (zustand persist) เก็บ `{ energy, lastRegenAt, lastDailyGiftDate }` — regen คำนวณ lazy ตอน rehydrate/interval จาก elapsed time (ไม่ต้องมี timer ฝั่ง server), HUD แสดง `⚡ n/10` + countdown ใน `/levels` และหน้าโหมดทุกหน้า

## กติกาปลดล็อก (client-side จาก zustand — ไม่ซีเรียสความปลอดภัย)

- **ด่านผจญภัย:** `unlocked(n) = n === 1 || stars[n-1] >= 1` — เข้า URL ตรงได้ แต่ `PlayGate` ('use client') ใน `/play/[level]` เช็ค progress.store: ถ้ายังล็อก → จอ "ต้องผ่านด่านที่ {n-1} ก่อนนะ 🔒" + ปุ่มกลับแผนที่ (ไม่ redirect เอง กัน loop)
- **โหมดพรีเมียม:** `ModeGate` เช็ค entitlement.store: `hasMode(m) = owns(m) || owns("bundle")` → ยังไม่ซื้อ = จอแนะนำโหมด + ราคา + ปุ่มไป /shop
- **Energy:** gate ตอนกด "เริ่มเล่น": ด่านใหม่/รอบพรีเมียมต้องมี ⚡≥1 (ยกเว้น Bundle) — หักใน handler แล้วค่อยเริ่มรอบ
- pure rules ทั้งหมดอยู่ `src/domain/services/rules.ts` (unlock, energy regen, ดาว) — unit test ได้

## Flow ซื้อ (PromptPay auto-approve — ตั้งใจไม่ตรวจสอบ)

จุดเข้า: 🛒 บนแผนที่/เลือกโหมด, การ์ดโหมดล็อก, EnergyEmptyModal → `/shop`

1. `PurchasePanel` โหลดสินค้าผ่าน `createProductRepo()` → เลือกชิ้น → สร้าง payload `buildPromptPayPayload(promptpayId, priceThb)` → render QR (`qrcode.react`)
2. ปุ่ม **"ชำระเงินแล้ว — ยืนยัน"** → `entitlement.store.approve(productId)` ทันที (order `{id, productId, amountThb, approvedAt, status:"approved"}`)
3. ไม่มี backend/ตรวจ slip — entitlement ใน localStorage _by design_ (ปลอมได้จาก devtools ยอมรับแล้ว)
4. ซื้อ Bundle → ธีม candy/space ปลดใน ThemeSwitcher + ⚡∞ ทันที (ธีมล็อกแสดงเทา+🔒 ใน switcher)

## Gameplay engine (game-screen.tsx — ใช้ร่วมทุกโหมด)

```
'loading' → (useEffect สร้าง tray สุ่ม) → 'idle'
'idle' → แตะ tile เติมช่อง + เสียงตัวอักษร → เต็ม → 'checking'
'checking' → ถูก → 'correct' (ฉลอง + อ่านคำ) → คำถัดไป | จบรอบ
           → ผิด → 'wrong' (mistakes+1, buzz+shake) → คืน tile → 'idle'
จบรอบ → 'levelComplete' (ผจญภัย: saveStars best-of, 3⭐ครั้งแรก +1⚡) / 'roundResult' (พรีเมียม: บันทึก stats)
```

- เช็คถูก/ผิดเทียบ**ตัวอักษร** ไม่ใช่ tile id (รองรับ EGG/BEE) · ดาว: ผิด 0–1 = 3⭐, 2–4 = 2⭐, 5+ = 1⭐
- สุ่มใน `useEffect` เท่านั้น (กัน hydration mismatch) · เสียงใน handler/effect · AudioContext lazy ใน user gesture · speech = enhancement (iOS ต้อง gesture)
- แตะช่องที่เติมแล้ว = คืน tile · header: ⏸ PauseMenu + progress + SoundToggle
- ต่อโหมด: time-attack เพิ่ม countdown 60s + score · listen ซ่อนรูป + ปุ่ม 🔊 ฟังซ้ำ · endless วนไม่จบ + streak · quiz ใช้ prompt รูป + ปุ่มตัวเลือก 3 คำ (ไม่ใช้ tray)
- `word-image.tsx`: `<img>` + `onError` → emoji ใหญ่ + คำแปลไทย (`key={word}` reset) — โลโก้ landing ใช้ `next/image`
